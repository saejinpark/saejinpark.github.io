## 소개

건축처럼 표준이 있는 개발을 지향하는 **제페토(Geppetto)**입니다.
[boostcourse](https://www.boostcourse.org/)에서 코드 리뷰를 받으며 공부를 시작했고, 웹 프론트엔드를 거쳐 지금은 iPhone과 Apple Watch 앱을 혼자 기획하고 디자인하고 만들어 출시하고 있습니다.

이 블로그에는 디자인과 개발을 공부하며 정리한 것을 씁니다.
[디자인 시리즈]({% post_url design/concept/2026-11-15-designSeriesHub %})는 웹에서 정리된 디자인 이론을 iOS와 SwiftUI의 언어로 다시 읽은 글 모음입니다.

## 교육

1. **부스트코스**
   - 웹 UI 개발: HTML, CSS, 웹 퍼블리싱, 시맨틱 마크업, 웹 접근성
   - 웹 백엔드: Java, SQL, Spring, MySQL
   - 웹 풀스택: HTML, CSS, JavaScript, Java, SQL, Spring, MySQL

2. **부스트캠프 Web·Mobile**
   - 버전 관리, JavaScript, 객체지향 프로그래밍, 함수형 프로그래밍, 비동기 프로그래밍

3. **코드스쿼드 프론트엔드 마스터즈 max** (2023.01 ~ 2023.09)
   - 정적 페이지 개발, 데이터 통신, 알고리즘 구현, 쇼핑몰 개발, 인터랙티브 웹사이트
   - React, TypeScript, 상태 관리, 컴포넌트 기반 개발, 최적화, 테스팅

4. **애플 디벨로퍼 아카데미 3기** (2024.03 ~ 2024.12)
   - CBL, HIG, Swift, SwiftUI, SwiftData
